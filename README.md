# Tor Baper Rasta Game
Welcome to the Tor Baper Rasta game! Navigate your rickshaw through the streets of Bangladesh while avoiding obstacles.

## Getting Started
1. Clone this repository or download the ZIP file.
2. Open `index.html` in your web browser.

## How to Play
- Click the "Start Game" button to begin.
- Use left and right arrow keys to move the rickshaw.
- Avoid the obstacles to keep your score increasing.

## Enjoy the Game!
